Food Macro Tracker PWA

এই ফোল্ডারের সব ফাইল একসাথে HTTPS ওয়েব হোস্টিংয়ে আপলোড করতে হবে। শুধু index.html ফোনে খুললে PWA install prompt/অফলাইন cache কাজ করবে না।

সহজ উপায়: GitHub Pages বা Netlify-তে পুরো ফোল্ডার deploy করুন। প্রকাশিত https:// URL Android Chrome-এ খুলুন > তিন ডট > Install app / Add to Home screen.

নিজের খাবার যোগ: অ্যাপের 'নিজের খাবার যোগ করুন' অংশে নাম ও প্রতি ১০০ গ্রাম/১০০ ml-এর kcal, protein, fat, carbs দিন। প্যাকেটের nutrition label বা নির্ভরযোগ্য ডাটাবেস ব্যবহার করুন। শুধু ইন্টারনেট চালু করলেই খাবারের সঠিক মান স্বয়ংক্রিয়ভাবে আসবে না।

ডাটা এই ডিভাইসের browser local storage-এ থাকে। নিয়মিত Backup ডাউনলোড করুন।
